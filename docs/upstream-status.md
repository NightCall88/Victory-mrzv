# Upstream status

This fork's README describes this fork. The state of the project it comes from,
its subsystem table and its debugging aids are upstream's and are kept there:

- [Marvisak/VIctory](https://github.com/Marvisak/VIctory#status-2026-11-23) —
  the base: loader, runtime services, Direct3D 12 back end, shader recompiler.
- [fxceless/victory-fork](https://github.com/fxceless/victory-fork) — the line
  this fork starts from, and the commits this fork's history sits on.

Both are GPL-3.0-or-later. Nothing of theirs is restated here, so that the two
do not drift apart; what changed in this fork is in the main README and in
[MEASUREMENTS.md](MEASUREMENTS.md).
